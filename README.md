# Lumière — LVMH Earnings Intelligence Agent

An AI agent that reads LVMH's quarterly earnings results, visualises the strategic trends,
and lets anyone interrogate the data in plain English through a live chatbot.

**Problem it solves:** Public companies reveal their entire strategy on earnings calls, but the
insights are buried in dense, hour-long disclosures. Lumière turns hours of analyst work into a
30-second conversation — ask "why did sales drop?" and get a sourced answer instantly.

## Features
- Live dashboard of LVMH revenue & organic growth (FY2023–9M 2025, real published figures)
- Division-by-division and regional breakdown
- Agent-flagged strategic findings (turning points, risks, strengths)
- **Live AI chatbot** grounded in the real earnings data (Google Gemini, free tier)

## Tech
HTML / CSS / JavaScript · Chart.js · Vercel serverless function · Google Gemini API
